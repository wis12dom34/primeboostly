Quick start

POST requests use form data. Responses are JSON. Start by listing services, then create an order.

List services

POST /api/v2
key=YOUR_API_KEY
action=services

Create order

POST /api/v2
key=YOUR_API_KEY
action=add
service=101
link=https://instagram.com/p/example
quantity=1000

Order status

POST /api/v2
key=YOUR_API_KEY
action=status
order=1248
